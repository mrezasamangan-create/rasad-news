# رصد | داشبورد خبری فارسی

یک رابط کاربری واکنش‌گرا و فارسی برای رصد خبرهای خاورمیانه، منابع رسمی و موضوعات منتخب. این نسخه شامل صفحه اصلی، جست‌وجو و فیلتر، ساعت/تاریخ تهران، منابع خبری، بخش سخنرانی‌ها، جایگاه رصد ماهواره‌ای و کارت‌های F-35 / F-22 / B-1B / B-2 است.

## اجرا در GitHub Pages

1. یک مخزن جدید در GitHub بساز و فایل‌های این پروژه را در شاخه `main` بارگذاری کن.
2. در مخزن به **Settings → Pages** برو و انتشار از شاخه `main` و پوشه `/ (root)` را انتخاب کن.
3. در **Settings → Actions → General**، گزینه دسترسی نوشتن به مخزن را برای workflowها فعال کن: **Read and write permissions**. گردش‌کار هر پنج دقیقه فایل داده را به‌روزرسانی و commit می‌کند.
4. در **Actions** اجرای `Update Rasad news data` را باز کن و یک بار **Run workflow** بزن.
5. برای ترجمه فارسی خودکار، در **Settings → Secrets and variables → Actions → New repository secret**، نام `OPENAI_API_KEY` و کلید API خودت را اضافه کن. بدون این secret، متن اصلی حفظ می‌شود و نباید آن را ترجمه‌شده فرض کرد. استفاده از API ممکن است هزینه داشته باشد.

> GitHub Actions زمان‌بندی دقیقِ تضمین‌شده ندارد؛ ممکن است اجرا با تأخیر انجام شود. رابط کاربری داده را هر ۵ دقیقه دوباره می‌خواند، اما خبر تازه فقط وقتی نمایش داده می‌شود که فایل داده توسط workflow به‌روز شده باشد.

## منابع و محدودیت‌های داده

- فیدهای RSS نمونه در `scripts/update_news.py` قرار دارند: Al Jazeera، Fox News، کاخ سفید، CENTCOM و NetBlocks. دسترس‌پذیری فیدها ممکن است تغییر کند؛ خطای یک منبع در log ثبت می‌شود و مانع پردازش بقیه منابع نیست.
- رویترز و العربیه در رابط کاربری به‌عنوان منابع قابل مراجعه نمایش داده می‌شوند، اما در این نسخه به‌دلیل دسترسی/مجوز فید پایدار، فید خودکار آن‌ها فعال نشده است. فقط از API یا RSS مجاز استفاده کن و شرایط استفاده هر ناشر را رعایت کن.
- برای Telegram، Instagram و X به API رسمی، مجوز و شناسه حساب‌های مشخص نیاز است. نام این شبکه‌ها در رابط آمده، اما جمع‌آوری خودکار پست‌ها تا افزودن اتصال معتبر فعال نیست. `EXTRA_RSS_FEEDS` فقط برای فیدهای RSS عمومی و مجاز است؛ قالب متغیر GitHub را به شکل JSON تنظیم کن.
- این پروژه به API اختصاصی FlightRadar24 یا داده نظامی زنده وصل نیست. پرواز هواگردهای نظامی ممکن است در سرویس‌های عمومی نمایش داده نشود؛ کارت‌ها عمداً وضعیت ساختگی نشان نمی‌دهند.
- تصویر حرارتی/ماهواره‌ای زنده در این نسخه دریافت نمی‌شود. برای نمایش تصویر معتبر به سرویس تصویری دارای مجوز، شناسه محصول، زمان ثبت و اطلاعات مکانی نیاز است. تصویر عمومیِ بی‌ارتباط نباید به‌عنوان عکس یک حمله یا آتش‌سوزی معرفی شود.
- خبرها خودکار راستی‌آزمایی نمی‌شوند و پرچم «خبر فوری» خودکار از روی کلمات حدس زده نمی‌شود. پیش از انتشار ادعای حساس، منبع اولیه و تأیید مستقل لازم است.

## ترجمه فارسی

وقتی `OPENAI_API_KEY` تعریف شده باشد، اسکریپت عنوان و خلاصه را با مدل پیکربندی‌شده به فارسی ترجمه می‌کند. وضعیت ترجمه با `translation_status: machine` ثبت می‌شود. این ترجمه ماشینی است و برای نام‌ها، اعداد و ادعاهای حساس نیازمند بازبینی است. بدون کلید API، عنوان و خلاصه اصلی نگه داشته می‌شوند؛ سامانه ترجمه جعلی تولید نمی‌کند.

## تنظیم فیدهای مجاز اضافی

در **Settings → Secrets and variables → Actions → Variables** متغیری به نام `EXTRA_RSS_FEEDS` اضافه کن. مقدار نمونه:

```json
[{"source":"نام ناشر","url":"https://example.com/feed.xml","kind":"news"}]
```

این نمونه را با URL واقعی یک فید عمومی و مجاز جایگزین کن.

## فایل‌ها

- `index.html` رابط فارسی
- `styles.css` طراحی واکنش‌گرا با تم قرمز و سفید
- `app.js` جست‌وجو، فیلتر، ساعت تهران و تازه‌سازی رابط
- `data/news.json` داده‌ای که در هر اجرا به‌روز می‌شود
- `scripts/update_news.py` دریافت RSS و ترجمه اختیاری
- `.github/workflows/update-news.yml` زمان‌بندی خودکار پنج‌دقیقه‌ای
